# lanej.io

Personal site for Josh Lane.

## Stack

- Hugo
- hand-written HTML templates
- native CSS
- GitHub Pages

There is no theme, frontend framework, package manager, or client-side JavaScript.

The Hugo source lives in this repository. The root also contains the current generated static pages so the existing GitHub Pages branch deployment can publish immediately while the site is rebuilt.

## Local development

```sh
hugo server -D
```

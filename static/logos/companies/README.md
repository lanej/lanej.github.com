# Company logo sources

Actual company marks for career identification, retrieved September 10, 2026.
These assets retain their original colors and geometry. They are displayed with
`contain` sizing inside matching circular frames, never stretched or recolored.
Company names remain in the adjacent text; the marks are decorative.
